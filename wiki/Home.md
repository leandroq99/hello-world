# Bem-vindo à Wiki - Estudo de Tecnologia

Este é um repositório dedicado ao **estudo e aprendizado contínuo** de tecnologias modernas de infraestrutura e automação.

## 🎯 Objetivo do Projeto

Documentar, organizar e compartilhar conhecimento sobre:

- 🐳 **Docker** — Containerização e orquestração
- 🤖 **Ansible** — Automação de infraestrutura
- 📚 **Anki** — Geração automatizada de flashcards para estudos
- 📖 Estudos e anotações gerais sobre tecnologia

## 📁 Estrutura do Projeto

| Pasta | Descrição | Arquivo Principal |
|-------|-----------|-------------------|
| **Docker/** | Notas sobre containerização e comandos Docker | `Docker_notes.txt` |
| **Ansible/** | Playbooks para automação de infraestrutura AWS | `*.yml` |
| **Anki/** | Ferramenta para geração de flashcards | `anki_gen.py` |

## 📚 Como Usar Este Repositório

1. **Explorar**: Navegue pelas pastas para encontrar o tópico de interesse
2. **Aprender**: Leia as notas, documentação e exemplos
3. **Praticar**: Execute os scripts e teste os exemplos em seu ambiente
4. **Contribuir**: Atualize e expanda conforme aprendar novos conceitos

- ✅ Exemplos práticos com comandos reais

- ✅ Atualização contínua com novos tópicos
