# 📖 Wiki do Projeto

Bem-vindo à wiki do repositório **Estudo de Tecnologia**!

Esta wiki contém documentação completa sobre Docker, Ansible e Anki.

## 🚀 Como Usar Esta Wiki

### No GitHub

1. Clique na aba **"Wiki"** no seu repositório
2. Você verá todas as páginas organizadas
3. Clique em qualquer página para ler

### Navegação

- **Menu lateral** (`_Sidebar.md`) — Acesse todas as páginas rapidamente
- **Links internos** — Clique em links azuis para navegar entre páginas
- **Busca** — Use `Ctrl+F` para buscar na página
